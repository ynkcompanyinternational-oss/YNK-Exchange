## GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the main branch and root (`/`).
5. Publish.

## Important production notes

The digital-asset form is intentionally a front-end demonstration. It does not collect or process payment credentials, execute blockchain transfers, or pretend that a human-operated settlement process is automated. Before production, connect it to an appropriate secure backend/payment provider and implement authentication, transaction records, compliance requirements, wallet-address validation, audit logs, and operational approval flows.

Investment figures in the visual dashboard are intentionally not presented as real performance data. The public portfolio button links to the external portfolio reference supplied by the client.
